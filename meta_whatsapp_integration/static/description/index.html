Meta WhatsApp Business API Integration

Professional WhatsApp Business messaging for Odoo 18

🚀 Key Features

  • Meta WhatsApp Business API - Official API integration
  • Template Messages - Pre-approved message templates
  • Contact Management - WhatsApp numbers in customer records
  • POS Integration - Send receipts via WhatsApp
  • Message History - Track all sent messages
  • Multiple Accounts - Support for multiple WhatsApp Business accounts

📋 Requirements

  • Meta WhatsApp Business Account
  • WhatsApp Business API access
  • Valid access token from Meta Business
  • Phone number ID from Meta

⚙️ Setup Instructions

  1. Install the module
  2. Go to WhatsApp → Configuration → Business Accounts
  3. Create a new business account with your Meta API credentials
  4. Test the connection
  5. Set up message templates (optional)
  6. Start sending messages!

📱 Usage

  • Send Messages: Use WhatsApp → Send Message or from customer records
  • POS Receipts: Send receipts directly from POS interface
  • Templates: Create and manage message templates
  • History: View all messages in WhatsApp → Messages

🔧 Configuration

You'll need the following from Meta Business:

- Phone Number ID: Your WhatsApp Business phone number ID
- Access Token: Permanent access token
- Business Account ID: Your WhatsApp Business account ID
- Webhook Verify Token: For receiving webhooks (optional)
